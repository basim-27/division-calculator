# ➗ Division Calculator

A simple **Division Calculator** built with HTML and JavaScript.  
It takes two numbers from the user and calculates the division result.

## 🌐 Live Demo

👉 [Open Division Calculator](https://basim-27.github.io/division-calculator/)

## 📌 About The Project

This is a beginner-friendly JavaScript project created to practice basic programming concepts such as:

- User input with `prompt()`
- Converting input into numbers using `parseInt()`
- Variables
- Arithmetic operators
- Division
- Displaying results using `alert()`

## 🛠️ Technologies Used

- 🟠 HTML5
- 🟨 JavaScript

## ⚙️ How It Works

1. The user enters the first number.
2. The user enters the second number.
3. JavaScript divides the first number by the second.
4. The result is displayed using an alert box.

### Example

```text
Enter the first number: 20
Enter the second number: 5

The result of division is: 4
